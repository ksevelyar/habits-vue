# Charts
## Requirements
* The dashboard displays charts for enabled chains.
* The dashboard provides 1 month, 4 months, and 1 year chart periods.
* The frontend derives start and end dates from the selected 1 month, 4 months, or 1 year label.
* The dashboard supports navigating to earlier periods.
* D3 renders smoothed charts from daily metric values.

## User scenarios
1. A user selects 1 month and views the Pull-ups chart.
2. A user navigates to the previous month and views its Pull-ups chart.
3. A user selects 1 year and views the Pull-ups chart.
